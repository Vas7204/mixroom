# Mixroom

Бесплатный офлайн-прототип для Android и iOS на Expo / React Native.

## Возможности

- 10 вкусовых идей, 5 направлений и общий каталог.
- Случайный подбор внутри направления без повтора предыдущего.
- Крупная карточка с процентами для мастера.
- Отправка текста через системное меню телефона.
- Офлайн-каталог 530 позиций восьми марок: поиск по названию и вкусовой ноте, фильтры по марке и TNG, переход к поиску из рецепта.
- Без аккаунтов, рекламы, оплаты, сервера и внешнего AI.

Рецептуры иллюстративные и не проверены мастером. Согласуйте бренды, крепость и пропорции на месте.

Каталог — справочный срез открытых списков на 20.09.2026. MUSTHAVE: 99 позиций по 9 страницам [официального ассортимента](https://musthave.ru/category/tabak-dlya-kalyana/). DARKSIDE: 77 уникальных позиций по [каталогу официального дистрибьютора](https://darksideshop.com/brands/darkside/?products=tobacco). Раздел TNG опирается на [официальный сайт сети](https://tangierslounge.ru/) и связанные открытые каталоги: Tangiers — 157 сочетаний вкуса и линейки, Bonche — 75, Dogma — 20, Trofimoff's — 56, BLANSH — 20, Azure — 26 зарегистрированных позиций. На официальном сайте TNG BLANSH указан как собственный запуск группы, а Tangiers и Azure — как проекты дистрибуции в истории сети. Публичное меню TNG просит уточнять ассортимент у мастера, поэтому метка TNG не означает наличие каждой позиции в каждом филиале.

Основной каталог обновляется командой `node scripts/import-catalog.mjs`, каталог TNG — `node scripts/import-tng-catalog.mjs` при наличии сети.

## Запуск на телефоне

1. Откройте терминал в папке `mobile`.
2. Выполните `npm install`, если зависимости ещё не установлены.
3. Выполните `npm start`.
4. Откройте проект через QR-код в совместимой версии Expo Go на Android или iOS. Компьютер и телефон должны находиться в одной сети. Шаблон использует Expo SDK 57; при несовместимости Expo Go потребуется соответствующая development build.

После установки отдельной сборки функции работают офлайн. Режим разработки через Expo Go требует соединения с сервером разработки для загрузки приложения.

## Проверки

`npx tsc --noEmit`

`node --experimental-strip-types --test recipes.test.mjs catalog.test.mjs tng-catalog.test.mjs`

`npx expo export --platform android --platform ios --output-dir build`

Экспорт проверяет JS-бандлы, но не создаёт APK/IPA. Для распространения нужны отдельные нативные сборки и проверка на физических устройствах. Публикация в магазинах не выполнена. Иконки пока из шаблона Expo.

## APK по ссылке

Готовая тестовая сборка находится в `release/mixroom-alpha-1.0.0.apk`. Это самостоятельный APK для Android 7.0 и новее; Expo Go и сервер разработки не нужны. Сборка подписана тестовым Android-ключом и предназначена для установки по ссылке или напрямую, а не для публикации в Google Play.

Профиль `preview` в `eas.json` создаёт самостоятельный APK без Expo Go и сервера разработки.

1. Войти в Expo: `npx --yes eas-cli@latest login` (вводить пароль только в терминале).
2. Запустить: `npx --yes eas-cli@latest build --platform android --profile preview`.
3. При первой сборке связать проект с аккаунтом Expo и создать Android signing key через EAS. Сохраняйте этот проект и ключ для последующих обновлений.
4. После успешной сборки EAS выдаст страницу установки и скачивания APK. Откройте ссылку на Android, скачайте APK и разрешите установку из этого источника, если Android попросит.

Ссылка появится только после успешной нативной сборки. Для другого приложения нужна отдельная сборка и уникальный Android package.

На Windows с кириллицей в пути Android Gradle Plugin требует `android.overridePathCheck=true`, настройка сохранена в `android/gradle.properties`. Prefab всё равно требует латинский путь для C++-этапа, поэтому локальный APK был собран из временной копии проекта. Проверены подпись APK v2, пакет `app.mixroom.mobile`, версия `1.0.0`, minSdk 24 и targetSdk 36.

# Mixroom

Бесплатное мобильное приложение для тех, кому надоело каждый раз придумывать новый вкус кальяна. Mixroom предлагает случайный микс, показывает пропорции и формирует понятный рецепт, который можно показать кальянному мастеру.

Сейчас в приложении:

- 530 вкусов популярных брендов;
- отдельный каталог марок, представленных сетью TNG;
- рекомендации и рандомайзер миксов;
- рецепт с пропорциями ингредиентов;
- автономная работа без регистрации.

Проект сделан на Expo и React Native для Android и iOS. Исходный код и инструкции по запуску находятся в папке [`mobile`](mobile/README.md). Готовая тестовая сборка Android публикуется в разделе **Releases** этого репозитория.

> Приложение предназначено для совершеннолетних пользователей. Наличие конкретных вкусов в заведении нужно уточнять у мастера.
